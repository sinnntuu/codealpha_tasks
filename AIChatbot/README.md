#  Artificial Intelligence Chatbot

A Java GUI-based AI Chatbot developed using Java Swing and basic Natural Language Processing (NLP) techniques.

This project was created as part of the CodeAlpha Java Development Internship.

 Interactive Chat Interface  
 Real-Time User Communication
