#  Stock Trading Platform

A Java GUI-based Stock Trading Simulator developed using Java Swing.

This project was created as part of the CodeAlpha Java Development Internship.

---

#  Features

 Simulate Stock Market Trading  
 Display Market Stock Data  
 Buy Stocks  
 Sell Stocks  
 Portfolio Management  
 Transaction History Tracking  
 Portfolio Performance Monitoring  
 GUI-Based Interface using Java Swing  
 Object-Oriented Programming Concepts

#  How to Run

## Step 1: Compile the Program

```bash
javac StockTradingPlatformGUI.java
```

## Step 2: Run the Program

```bash
java StockTradingPlatformGUI
```

---

#  Application Modules

##  Market Data
 Displays available stocks
 Shows stock symbols, company names, and prices

##  Buy/Sell Operations
 Buy stocks using available balance
 Sell owned stocks
 Automatic balance updates

##  Portfolio Tracking
 View owned stocks
 Check portfolio value
 Monitor total net worth

##  Transaction History
 Track all buy/sell transactions
 Displays quantity, stock price, and total amount
