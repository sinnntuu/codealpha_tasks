# Student Grade Tracker

A Java GUI-based application developed using Swing to manage student grades efficiently.

This project was created as part of the CodeAlpha Java Development Internship.

---

#  Features

 Add Student Details  
 Store Student Marks  
 Calculate Average Marks  
 Find Highest Marks  
 Find Lowest Marks  
 Display Student Records in Table Format  
 GUI-Based Interface using Java Swing  
 Input Validation for Marks
